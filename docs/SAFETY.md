# 安全和验证边界

- 只支持明确核验过的 Redmi Book Pro 15 2022 / 6800H / P1111 / P.11。不是其他 Redmi、小米或其他型号的通用偏移配置。
- 手动调速替代固件正常曲线。0% 请求会停转，CPU 温度不代表 GPU、VRM、SSD、电池或键盘表面温度。
- 95°C 是用户选择的软件紧急门限，不是建议持续工作温度；没有故意加热验证该分支。不要取消系统/固件自身的保护。
- 95°C 前仍执行停转上限、60°C 最低输出和 80°C 满速规则；不存在“所有风扇一直停到 95°C”的模式。
- 退出、失联、无效传感器、真实失速时尝试恢复固件自动；独立看护不能保证全进程被结束、内核故障、掉电或所有睡眠/恢复情况下的恢复。
- 不使用未知低速参数做无人值守长时间负载。阈值附近可能反复启停；最低能稳定旋转/重新启动的输出必须在实际设备上验证。
- 0% 目标不等于真实瞬时 0 RPM；低输出/RPM 闭环和长期曲线的全面验证尚未完成。
- 60%/100%/自动恢复及旧版看护失联恢复有原开发机实测；新控制逻辑主要经离线边界和 UI 回归。CI 通过不是硬件安全认证。
- 若显示恢复未确认，请保留日志并立即检查系统，不要同时强制结束全部看护进程。
- 不与其他 EC / 风扇控制器同时接管；不要修改模块签名、内核安全策略或驱动白名单。
- 自动启动只启动非管理员托盘，不会绕过 UAC。未连接前不监测硬件，也不控制风扇。

发布前请维护者自行复核代码、许可与目标硬件。二进制未进行 Authenticode 签名；校验哈希只确认文件完整性，不表示厂商认证。
